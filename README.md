# Admetos Labs

Five-page Admetos website adapted from mosnin/pwilms at commit 31d5fbf02e74200b041a081683d5dd1439c14d46. The original 16 animation vendor files are preserved byte-for-byte. Includes the additional supplied accordion implementation.

## Run

```sh
npm ci
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

Routes: `/`, `/mission/`, `/projects/`, `/lab/`, `/contact/`.

Page content is generated by `scripts/build-pages.py`. Shared behavior lives in `src/main.js`; site styling in `src/styles/site.css`; original component implementations in `src/vendor`.

Vercel build configuration is included. The connection between this repository, the existing Vercel project, and admetos.org has not yet been verified. Build and static link checks pass; visual and interaction acceptance is pending.
