# Admetos

Admetos content using the original P Wilms layouts and motion system.

Run `npm ci`, `npm run build`, then `npm run preview`.

`scripts/build-pages.py` generates all 27 routes from the source shell and Admetos content. Product and system data live in `content/`. The exact source stylesheet is `src/styles/site.css`; brand/content integration is isolated in `src/styles/admetos.css`. Do not append redesign overrides to the source stylesheet.

See `references/source-restoration.md` for source commit, page mapping and verification boundaries.
